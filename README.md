# Scuderia — легенды Ferrari F1

Адаптивный одностраничный сайт о наследии Scuderia Ferrari и её легендарных пилотах. Реализован на HTML, CSS и vanilla JavaScript без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере. Для локального предпросмотра через HTTP можно выполнить в этой папке:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Примечание об изображениях

Фотографии пилотов и болида загружаются с Wikimedia Commons. Для их отображения требуется подключение к интернету. Если изображения используются в публичной публикации, проверьте условия лицензирования и атрибуции каждого файла.
